# CET-4 词汇专项（words）

> 本目录是跨 Chat、Work、Codex 会话使用的 **公开词汇学习资料入口**。  
> **个人掌握进度、原始答题与错词记录放在私有仓库** `meetjor/notions`，不在这里公开。

## 词汇专项说明

- 词表：用户自备《英语词汇_A4整理版》，16 Lesson，合计1,941词。
- 目标：提高四级**阅读英译中识别**，优先达到425分，争取450分。
- 方式：以 Lesson 为单位快速覆盖，四选一测试，允许选“答对但不确定”与“不会／跳过”。
- 学习节奏：争取一天一 Lesson，但不强制；旧词短时复测，不耽误主进度。
- 首测分类：掌握、答错、不确定、跳过。首次答错或跳过 **不等于顽固词**。
- 正式每日 Day 的词汇任务与这一专项是两个不同通道；不要把词汇专项的提交等同正式Day完成。

## 其他会话如何读取真实掌握情况

使用已连接且有授权的 GitHub，在 **私有仓库** 按下面路径读取：

1. `meetjor/notions/AGENTS.md`
2. `meetjor/data/AGENTS.md`
3. `meetjor/notions/四级/记忆/当前交接.md`
4. `meetjor/notions/四级/记忆/词汇专项/Lesson01-02_首测完整档案.md`
5. 继续查看 `meetjor/notions/四级/记忆/当前备考状态.md` 和 `meetjor/notions/四级/记忆/下一日出题依据.md`

**第4项是当前已归档的词汇首测基线**；若后续新增 Lesson 或复测，以私有交接文件里标注的最新词汇档案为准。不要靠旧会话或日历猜测进度。

## 用于其他四级学习材料

- **阅读**：优先在原创阅读、同义替换、长句理解中自然复现高价值薄弱词；不为塞词牺牲真题难度和可读性。
- **写作与翻译**：精选可实际使用的词与搭配做迁移练习；不要把所有“会认”词强制升级为会拼写。
- **间隔复习**：优先针对首测答错与不确定词；跳过词先补词义；由私有记录决定复测对象。
- **来源与隐私**：公开材料中可提供中性词汇知识，但不写入用户个人正确率、错词名单或学习状态。
