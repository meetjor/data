# CET-4 18篇作文与重点词汇学习库

生成日期：2026-10-14（北京时间）。目标：掌握不同四级作文任务的组织方式，并把重点词汇转化为能主动写出的词、搭配与句子。全部为原创学习范文，人物、活动、书名和数字若出现均为练习设定，不是用户个人经历或研究证据。

18篇正文每篇145–161词，总计2805词。词源是用户提供的《英语词汇_A4整理版》：1,941条记录、1,940个不同词头。实际覆盖**279个词表词头**，其中**208个设为重点学习词**（每篇12项，合计216项，重复8项不重复计数）；**72个词头在至少两篇中复现**。覆盖约占词表14.4%，不宣称覆盖全部或已掌握。

## 使用方法

每次选一篇：理解任务与三段内容→学两个结构→认读12个词→遮住英文主动回忆→到PDF写两句和一段新主题。可分多次完成，不一次背18篇，也不把本册自动叠加为每日额外任务。若想练完整作文，可在理解后独立写120–180词、用30分钟；有困难先完成短段落。

MD负责讲解与范文，PDF负责正式练习。答案在PDF的STOP之后。记录不确定之处与原始作答，交Chat批改；本册生成不推进Day编号、不写入已掌握状态。

## 题型覆盖范围

依据[项目39套作文任务观察](https://github.com/meetjor/data/blob/main/cet4/writing/2021-2026_39套作文题型观察.md)归纳六个主要任务群：观点3篇、提案3篇、重要性2篇、描述/报告/推荐6篇、申请/邀请2篇、影响/未来应用2篇。这是教学分类，不是官方固定题型，也不是预测未来所有命题。

先看写作身份、任务动作、具体内容点，再选结构。题干是提出未来方案，不能写成过去活动报道；题干是邀请，不能只谈某事重要。图画、图表、指定开头是题目呈现方式，不能只凭它们决定全文体裁。本册主要覆盖已核验39题的任务类型；不把没有核验的历史图表题伪称已覆盖真题。

## 词汇计数口径

只统计18篇英文正文中实际出现的词表词头，译文、题干、词表讲解、练习和称呼落款不计入。屈折形式映射回原词，如facilities→facility、classified→classify。少量明确的词族变化，如environmental→environment、evaluation→evaluate，也映射回同一原词；文中形式和词性另标。

若派生词本身就是词表独立词头，优先按该独立词条计数，不同时把上游词头也记一次。同一个词在18篇重复出现，只算一个；拼写变体如catalog/catalogue、judgment/judgement归为同一词条。基础词与必要表外词正常使用，不为限制词表破坏英语，也不计入词表覆盖数。

本册是第一批作文与词汇材料，剩余词表仍需后续文章和复习覆盖。出现过、练过和稳定掌握是不同状态。
