# CET-4 单词复习总表｜80天滚动复习

> 用途：把每天学过的词集中到一个长期复习入口，避免 Day 10 以后忘掉 Day 01。  
> 本表只整理每日资料中已经出现过的词，不额外塞新词。

## 使用方法

每天开始新内容前，用 **10～15分钟** 做滚动复习：

- 【会拼写】：先遮住英文，看中文主动写英文；再做英→中确认。
- 【会认】：只做英→中，不强迫默写。
- 【会用搭配】：遮住英文，根据中文写完整搭配。
- 写错或想不起来：标记为 ★，次日再次复习。
- 连续两次都能主动写对：可以降低复习频率，但不要永久删除。

建议复习节奏：**当天 → +1天 → +3天 → +7天 → +14天 → +30天**。  
实际每日任务仍会根据小检测结果调整，易错词会提前回炉。

## Day 05 实际易错追加（2026-09-27）

近期优先复习：

- ★ **prevent** — 首次中→英写成 `privent`，但随后小检测已正确写成 `prevent`；继续短间隔复现一次即可。
- ★ **special** — 首次中→英未能提取；继续短间隔复现。
- ★ **province** — 英→中识别未成功；保留【会认】，暂不强制中文→英文。
- ★ **originally** — 英→中识别未成功；近期再次出现。
- ★ **be produced in...** — “产于……”；主动回忆时写成 `in produce`。
- **rich experience** — 丰富的经验；experience 表示“经验”时通常不可数。

- ★ **rather than** — 而不是；Day 05 阅读55题因未理解该逻辑词而误选。

- **Tieguanyin is produced in... / comes from...** — ……产于……

## Day 07 复习补充（2026-10-03）

以下是词形、搭配与输出复习补充；不另算一个新Day，不改变上方70个会拼写词、35个会认词的核心累计数。新增词族先认识并会用高价值词组，不全部升级为默写要求。

### 已学词对比与词形

| 对比 | 复习要点 | 示例 |
|---|---|---|
| possible / available | possible：可能的；available：可用的、可获得的。available仍按会认。 | a possible reason；available resources |
| digest / digestion | digest动词；digestion名词。 | improve digestion — 促进消化 |
| technology / skill | technology：技术；skill：技能。 | use technology；develop practical skills |
| affect / effect | affect动词；effect名词。情态动词后用原形。 | Technology can affect learning. |
| suggest / suggestion | suggest动词；suggestion名词。 | suggest doing sth.；some suggestions — 一些建议 |

### 高价值表达

- **be based on reliable evidence** — 基于可靠证据；Research should be based on reliable evidence.
- **make good use of...** — 充分利用……；常用结构不加a，保留of。
- **information from different sources** — 来自不同来源的信息；information不可数。
- **learning efficiency** — 学习效率；efficiency /ɪˈfɪʃənsi/，名词。
- **learning tasks** — 学习任务；task /tɑːsk/，可数名词。
- **spend more time and think carefully** — 花更多时间并认真思考；time表示时间量时不可数，并列动作spend与think形式一致。
- **depend too much on...** — 过度依赖……；avoid depending too much on...。
- **check their work** — 检查他们的作业/工作；此义的work通常不可数。
- **some suggestions / some advice** — 一些建议；suggestion /səˈdʒestʃən/可数，advice不可数。
- **not always right** — 并不总是正确；always /ˈɔːlweɪz/，注意完整拼写。
- **be used by students** — 被学生使用；by引出被动结构中的动作执行者。
- **plant growth / how plants grow** — 植物的生长 / 植物如何生长；growth /ɡrəʊθ/先作词族补充。

### 阅读识别

- **tend to...** — 往往……；倾向于……，不是“期待”。
- **challenge an idea** — 对某个看法提出质疑；和support an idea（支持某个看法）对比理解。
- **impression** — 印象；first impression — 第一印象。
- **reach a conclusion** — 得出结论。

### 短句复现

- Technology **helps** people learn.
- AI tools **are** useful, but they **can make** mistakes.
- Students should compare **information from different sources**.
- Some learning tasks require students **to spend more time and think carefully**.

## Day09复习点：选词/改错已较稳定，主动造句继续加强

- ★ **evidence**（n.不可数）：reliable evidence；不要随意写`evidences`。
