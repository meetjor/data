## 说明

- 每日资料按北京时间编号和安排。
- 单词尽量提供音标、词性、词义、常用搭配和搭配译文。
- 主书面顺序为旧词复习 → 新词 → 基础语法 → 小检测 → 翻译 → 作文 → 阅读。听力由用户在「不背单词」自主训练。
- 下一天内容根据上一天检测结果动态调整，不机械提前生成。
- 私人学习状态、检测表现和长期会话记忆不放在本公开仓库。
